# Security

## Supported versions

| Version | Supported |
|---------|-----------|
| `master` and the latest `0.1.x` release | :white_check_mark: |
| Older releases | :x: |

Redax is pre-1.0. Security fixes are best-effort and are made against the
latest development line. Please upgrade before reporting an issue when
possible.

## Reporting a vulnerability

**Please do not file a public issue.** Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
for this repository.

## What to include

Include the affected commit or release, deployment mode, reproduction steps,
impact, and whether any sensitive data was exposed. Do not include real PII in
the report; use synthetic examples and redact logs or screenshots.

We will acknowledge and triage reports as capacity allows. Fix timing depends
on severity, exploitability, and the availability of a safe patch.

Thank you for helping keep `redax` and its users safe.
